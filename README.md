# Онлайн-школа Ключ - Лендинг

Бета-версия лендинга для онлайн-школы "Ключ", созданная на Vue.js 3.

## 🚀 Технологии

- Vue.js 3 (Composition API)
- Vite
- CSS3 (Modern features)

## 📦 Установка

```bash
npm install
```

## 🛠️ Разработка

```bash
npm run dev
```

Сервер разработки запустится на http://localhost:3000

## 🏗️ Сборка

```bash
npm run build
```

Собранные файлы будут в папке `dist`
